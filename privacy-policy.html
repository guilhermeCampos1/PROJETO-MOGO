This tool accesses Google Ads account data solely for campaign management, reporting, and optimization. Data accessed includes campaign performance metrics, ad creative information, and account structure data through the Google Ads API.

All data accessed via the Google Ads API is used exclusively for:

No data accessed through the Google Ads API is shared with third parties. All information remains confidential and is used solely for internal management of advertising accounts.

4. Data Security

All API credentials and access tokens are stored securely and are never exposed publicly. Access is restricted to authorized users only.

This tool complies with the Google Ads API Developer Policies. Usage is limited to managing advertising accounts for which I have authorized access.
